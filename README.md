# Consultorio Pediátrico

App de un solo archivo (`index.html`, sin conexión) para escribir evoluciones de historia clínica pediátrica. Autor: Gonzalo Gabriel Pereira.

- `index.html`: toda la app.
- `PROYECTO.md`: reglas de trabajo, estado e historial. Leer antes de tocar nada.
- `MEJORAS_100.md`: plan de 100 mejoras, en orden.

Una tarea programada diaria implementa las mejoras y sube cada versión a la rama `main`.
